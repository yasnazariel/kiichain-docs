# Kii — معرفی کوتاه (نسخهٔ فارسی)

Kii یک پلتفرم هیبرید برای معاملات on-chain در بازارهای نوظهور است که هدفش فراهم کردن نقدینگی و تسویهٔ پرداخت‌های بین‌مرزی با استفاده از استیبل‌کوین‌ها و توکن‌های دارایی واقعی است.

## ویژگی‌های اصلی
- موتور تطبیق هیبرید (On-chain liquidity + centralized pricing)
- پشتیبانی از on/off ramps و API برای یکپارچگی با اپ‌ها
- رعایت استانداردهای KYC/AML در حوزه‌های قضایی مختلف

برای مستندات کامل‌تر و راهنمای توسعه‌دهنده‌ها به https://docs.kiiglobal.io مراجعه کنید.
